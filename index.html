Sistem Ujian & Anti-Cheat Siap

Paket 40 soal dan urutan pilihan jawaban (A, B, C, D) akan diacak secara otomatis khusus untuk sesi ujian Anda saat tombol mulai ditekan.

Peraturan Ketat Anti-Curang (Wajib Dipatuhi)

  • Aplikasi akan otomatis masuk ke Mode Layar Penuh (Fullscreen) saat ujian dimulai.
  • Dilarang berpindah tab, membuka aplikasi lain, minimize layar, atau split-screen.
  • Sistem memberikan batas maksimal 3 kali peringatan. Pada pelanggaran ke-3, ujian otomatis berhenti dan dikirim dengan status "Diskualifikasi (Curang)".
  • Klik kanan, blok/seleksi teks, copy-paste, dan pintasan keyboard (F12, Ctrl+C/V, dll) dinonaktifkan sepenuhnya.

Panduan Integrasi Google Sheets (Untuk Guru)

1. Token Ujian Aktif: MTK9SAS (dapat diubah pada variabel EXAM_TOKEN di dalam kode HTML).

2. Cara Menghubungkan ke Google Sheets:

  1. Buka Google Sheets baru, klik menu Ekstensi > Apps Script.
  2. Tempelkan kode berikut lalu klik Deploy > New Deployment > Web App (Akses: Anyone / Siapa saja).
  3. Salin URL Web App yang muncul dan tempelkan ke variabel GOOGLE_SCRIPT_URL di file HTML ini.
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Waktu", "Nama Lengkap", "Kelas", "Skor", "Status", "Jumlah Terjawab", "Detail Jawaban"]);
  }
  sheet.appendRow([
    data.waktu, data.nama, data.kelas,
    data.skor, data.status, data.jumlah_terjawab, data.detail_jawaban
  ]);
  return ContentService.createTextOutput(JSON.stringify({status: "success"}))
    .setMimeType(ContentService.MimeType.JSON);
}
